# 🚲 Bike Sharing Dashboard

Dashboard analisis data penyewaan sepeda harian berdasarkan dataset Bike Sharing 2011–2012.

## Struktur Direktori

```
submission
├── dashboard
│   ├── main_data.csv
│   └── dashboard.py
├── data
│   └── day.csv
├── notebook.ipynb
├── README.md
├── requirements.txt
└── url.txt
```

## Setup Environment

```bash
pip install -r requirements.txt
```

## Menjalankan Dashboard

```bash
cd submission
streamlit run dashboard/dashboard.py
```

Dashboard akan terbuka otomatis di browser pada alamat `http://localhost:8501`.
